# Simple Calculator

A lightweight, responsive calculator built with plain HTML, CSS, and JavaScript. No dependencies or build tools are required.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear and delete controls
- Keyboard input support
- Responsive layout and accessible button labels

## Run locally

Clone or download this repository, then open `index.html` in your web browser.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Enter a decimal point |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` | Clear the calculator |
